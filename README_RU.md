# AI Meeting Processing Engine

AI-система автоматической обработки встреч, разработанная на **n8n**. Workflow автоматически расшифровывает голосовые сообщения, извлекает задачи, формирует краткое содержание встречи, сохраняет данные и создаёт события в Google Calendar.

![Workflow](workflow.png)

Автоматическая обработка записей встреч с использованием искусственного интеллекта.

---

# Бизнес-проблема

После проведения встреч сотрудники тратят значительное количество времени на составление итогов, выделение задач, заполнение трекеров и календарей.

Такой процесс повторяется регулярно, занимает много времени и подвержен человеческим ошибкам.

---

# Обзор решения

Workflow автоматически:

- получает голосовое сообщение из Telegram;
- преобразует речь в текст с помощью Whisper;
- анализирует содержание встречи с помощью AI;
- извлекает задачи и ключевую информацию;
- сохраняет структурированные данные в Google Sheets;
- создаёт события в Google Calendar при обнаружении даты встречи;
- отправляет краткое резюме встречи обратно в Telegram.

# Workflow

```text
Telegram Voice Message
          │
          ▼
Преобразование речи в текст
          │
          ▼
AI-анализ встречи
          │
          ▼
Подготовка данных
          │
          ▼
Разделение задач
          │
      ┌───┴─────────┐
      │             │
      ▼             ▼
Google Calendar  Google Sheets
      │
      ▼
Отправка итогов в Telegram
```

---

# Архитектурные решения

- Whisper используется для преобразования речи в текст.
- Structured Output обеспечивает предсказуемый JSON-ответ AI.
- Каждая извлечённая задача обрабатывается независимо.
- События создаются только при обнаружении даты встречи.
- Google Sheets используется как постоянное хранилище задач.
- Telegram является основным каналом взаимодействия с пользователем.
